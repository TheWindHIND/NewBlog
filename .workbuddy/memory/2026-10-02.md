## 重要坑：本环境 push 必须用系统 Git
- WorkBuddy bash 默认 PATH 里的 git 是 PortableGit（/mingw64/bin/git），它不认 `http.schannelCheckRevoke=false`，走本地代理（127.0.0.1）时 TLS 握手报 CRYPT_E_NO_REVOCATION_CHECK 失败。
- **正确姿势**：用系统 Git 并加参数：
  `"/c/Program Files/Git/cmd/git.exe" -c http.schannelCheckRevoke=false push`
- 全局 .gitconfig 已写入 `http.schannelCheckRevoke=false`（系统 Git 生效）。
- curl 调 GitHub API 需加 `--ssl-revoke-best-effort`。

### 关键决策与坑
- **芙宁娜异色瞳正典配色（用户纠正）**：左眼深蓝虹膜+浅蓝瞳孔，右眼浅蓝虹膜+深蓝瞳孔，瞳孔水滴形（尖朝上）。
  主题切换按钮已改为该配色；猫猫立绘也用图生图改成交叉规则（图像左=浅蓝虹膜+深蓝水滴瞳，图像右=深蓝虹膜+浅蓝水滴瞳）。
- **生图透明背景的坑**：ImageGen `background:"transparent"` 实测会产出**烘焙进像素的 24px 灰白棋盘格**（#FBFBF9/#E5E3E1），
  sharp 报 hasAlpha:false，与角色白裙银发几乎同色无法抠图。→ 改用**绿幕方案**：`background:"opaque"` + 提示词要求
  「flat uniform pure chroma key green (RGB 0,255,0)」，再用 scripts/key-cat.cjs 按 `g - max(r,b)` 阈值抠图 + despill。
- **右下角水印**：生成图右下角有「AI生成 WORKBUDDY」水印，会撑大 alpha 包围盒 → 抠图时强制把 `x>76% && y>88%` 区域 alpha 置 0。
- **睁眼/闭眼对齐**：以第一张图的 alpha 包围盒为准统一裁切两张，保证交叉淡入眨眼不抖。
- **分层切分**（scripts/slice-cat.cjs）：头部下沿 47.5%、身体上沿 44.5%（重叠 2.5px 羽化）；尾巴用多边形遮罩从身体挖出
  （沿裙子右轮廓，轴心 74%,76.5%），身体挖洞多边形向右外扩 2.2% 避免旋转时露背景。测试合成图确认无缝。
- **图层产出**：public/images/cat/aylen-{head,head-closed,body,tail}.webp，共约 280KB；中间产物放 raw-assets（已 gitignore）。
- **层叠上下文坑**：给 `main` 加 `position:relative; z-index:1` 会形成 stacking context，导致灯箱(z-400)/幕布(z-460)
  被 header(z-50) 盖住。→ 改为 `.stage-frame { z-index:-1 }`（body 底色传播到画布，-1 仍可见），不给 main 设 z-index。
