## 第四轮：猫耳贝雷帽 + 眼睛水滴层次（用户已确认上一轮造型合适）

用户反馈：①贝雷帽做成**猫耳贝雷帽**；②眼瞳里的水滴形不够像，参考图 `E:\小米互传\1776347058597.jpeg` 的眼睛层次。

### 关键教训：图像模型做不了"外科级微改"
- 直接拿整只立绘做图生图（即使 `input_fidelity:"high"` + "keep pixel-identical"），模型仍会**整只重画**：
  头身比变小、头发变短、眼睛变小 → 完全不是"微小更改"。试了 2 次都失败。
- **正解：局部裁剪重绘**。把帽子那一段裁出来（x 全宽 × y 0~33.5%）合成到绿幕画布 → 只把这**局部**送去重绘 → 模型只能改这一块。
- **又一个坑**：把重绘结果整块贴回去，会让头发/线条被 AI 重绘"糊掉"（画质软化）。
- **最终正解：只取"新增像素"**。掩膜 = 原图透明处 ∩ 重绘有内容处，再向下膨胀 24px 让耳根压进帽面、羽化 1.5 → 只把新长的猫耳贴回去，**原画像素 100% 不动**。

### 眼睛层次：本地矢量重绘（`scripts/eyes-cat.cjs`）
- 参考图层次拆解：外层深色虹膜环 → 虹膜竖向渐变 → **水滴形瞳孔**（顶点切线竖直=尖锐、底部圆润、自带描边+内渐变）→ 左上大高光 → 底部月牙反光。
- 做法：按"蓝色"阈值定位虹膜可见区 → 逐行取左右边界 + 逐列填缝得到**眼睛内腔掩膜**（掩膜不含原画深色描边，所以原轮廓全保留）→ 掩膜内矢量重绘 → 3×3 两轮箱式模糊羽化后 alpha 混合。
- **坑**：`sharp` 单通道 raw 图 `.blur()` 会变成 3 通道取不回 → 自己写箱式模糊。
- **坑**：底部月牙必须画在瞳孔**之前**，否则会把瞳孔下半截盖白（曾误判成"水滴形状不对"）。
- 配色按正典异色瞳交叉规则：观者左眼=亮蓝虹膜+深蓝水滴；观者右眼=靛紫虹膜+亮青水滴。
- 虹膜定位实测：左眼中心 (29.95%, 49.70%) rx=5.01% ry=3.50%；右眼 (54.95%, 49.22%) rx=5.44% ry=3.76%。

## 第七轮：猫尾黑线修复 + 荒/芒切换图标重做

### 1. 文章页顶部「一条黑线」= `<use>` 的影子内容拿不到 CSS

**根因**（构建产物里能直接看到）：
```css
.ct-read[data-astro-cid-vql3dtbt] path[data-astro-cid-vql3dtbt]{fill:url(#ctGrad)}
```
`CatTailProgress.astro` 里尾巴主体写成 `<g id="ctTail">` 放进 `<defs>`，再用
`<use href="#ctTail" class="ct-read">` 渲染两遍。`<use>` 克隆进 shadow tree 的内容：
- 不被文档选择器命中；也**不带 Astro 的 scoped 属性**（双重失效）；
- → 路径退回 SVG 默认 `fill:black`，于是顶部出现**一条黑线**（尾巴尖是真实节点所以仍是蓝的，更容易误判）。

**修法**：模板里用 `[unread, read].map()` **渲染成两组真实节点**（几何由前端生成，复制一份零成本）。
顺带修掉 `.ct-unread .ct-fur path` 缺 `stroke` 导致未读绒毛**隐形**的问题（补 `stroke: var(--accent)`）。

**校验**：生产 `dist` 里 `ct-read` 节点带 cid、CSS 选择器逐个命中 → 修复成立。
对照图 `raw-assets/tail-preview/01-猫尾修复.png`（用 dev HTML 的真实标记离屏渲染）。
