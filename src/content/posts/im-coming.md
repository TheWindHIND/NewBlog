做这个页面的动机很朴素：大部分个人网站对来访者是「无感」的——你不知道谁推开了门，对方也感觉不出这是谁的地方。我想反过来一次，让人打开链接的第一秒就被点名。

现在的效果是：黑底、绿字、一道扫描光扫过屏幕，几行闪烁的启动日志，然后一句字符解码后落定的话——

> bro,你在四川省广安市对吧，我马上来

在线版本：[im-coming](https://thewindhind.github.io/im-coming/)。

## 一句话背后的两类东西

要说出这句话，只需要两样：一个 IP，和一个能把 IP 翻译成省市的接口。剩下的全是包装。

### 定位：五层降级

第三方的定位接口都不太稳，所以链路做成了逐级降级，每一跳都挂了 3 秒的 `AbortController` 超时：

1. `myip.ipip.net` 拿纯 IPv4 → 高德 V3 传 `ip` 参数（主力，最快也最准）
2. 同一个 IPv4 → `ipwho.is` 传 `ip` 参数（高德失败时接管）
3. 拿不到 IPv4 → 高德 V3 直连，用请求方 IP
4. 高德彻底不通 → `ipwho.is` 直连
5. 全挂 → 兜底文案「bro,你在某个神秘的地方对吧，我马上来」

这里的顺序不是随便排的：**先用国内服务拿 IP，再拿这个 IP 去问高德**，比直接让高德看请求方 IP 准得多——国内 IP 走国内接口，省界市界基本不飘。`ipwho.is` 排在高德后面，是留给境外访问者的一道备用。

顺带解决了「等定位」的观感问题：定位请求和 600ms 的定时器赛跑，赢了就直接出结果，输了先播一句 `LOCATING...`，等结果回来再用 glitch 切一次文案。这样无论接口多慢，页面都不会僵在那里。

### 密钥：不想被明文扫走

定位服务要 key。虽然前端页面里的密钥本质上藏不住，但也没必要主动写在明面上被人一把抓走，所以拆成四段 Base64，运行时拼起来再 `atob`：

```js
var _p1 = 'YTg4N2RlYzY=';
// … 四段分别在文件里各占一行
var LOC_KEY = atob(_p1) + atob(_p2) + atob(_p3) + atob(_p4);
```

这挡不住铁了心的人，但能挡掉自动扫 key 的脚本。够用了。

## 入场的那一秒钟

整场演出大概 1 秒，按顺序是：

1. 一道绿色扫描光从上扫到底（`0.9s`，`ease-out`）
2. `INITIALIZING_SYSTEM` 高频闪烁（`0.07s` 步进）
3. glitch 阶段：红蓝分色双层文字 + `clip-path` 上下切条，配 `0.08s` 抖动
4. 字符解码动画落定目标文案（`350ms`）

第二步那个字符解码是整段里我最喜欢的一小段：

```js
function decodeTo(target, duration) {
  var len = target.length;
  var revealed = new Array(len).fill(false);
  var start = performance.now();

  function frame(now) {
    var p = Math.min((now - start) / duration, 1);
    var count = Math.floor(p * len);        // 按进度决定「已揭晓」到第几个字
    for (var i = 0; i < count; i++) revealed[i] = true;

    var out = '';
    for (var j = 0; j < len; j++) {
      out += revealed[j] ? target[j] : randChar();  // 未揭晓的位置吐随机字符
    }
    setText(out);
    if (p < 1) requestAnimationFrame(frame);
    else setText(target);
  }
  requestAnimationFrame(frame);
}
```

用 `requestAnimationFrame` + `performance.now()` 算进度，而不是 `setInterval` 数次数——慢机器上动画会掉帧，但**时长不会被拖长**，节奏始终一致。

落定之后还有一个小尾巴：句首的 `bro,` 单独染成稍亮的青绿，可以点，点开是新窗口的 B 站主页；文字稳定 2 秒后它自己崩坏闪一下（`0.28s`，`steps(1)`），再恢复原样。这个「你以为是链接、它却抖了一下」的错位，比一直发光有意思。

## 那点恶作剧

如果访问者来自境外 IP，有 15% 的概率会在文案下方多出一段正经得不能再正经的提醒，照着法规原文写的，末尾还附一句「已记录你的 IP：x.x.x.x」。

两个分寸：一是**只在境外 IP 出现，且只有 15% 概率**，国内访客一辈子看不到，不打扰正常人；二是用打字机效果一个字一个字往外蹦（每字 22ms），那种慢慢逼近的荒诞感才是笑点。

## 隐私这件事

一个能报出你在哪的页面，必须把自己的边界说清楚：

- 页面只做两件事——向 IP 接口要一个地址、把这个地址交给定位接口；不写 cookie、不落库、不往任何自己的服务器发数据（因为压根没有服务器）
- 全部逻辑跑在浏览器里，单文件静态页，GitHub Pages 托管
- 但要说实话：IP 和定位查询都会经过第三方接口，这些请求本身对接口方是可见的——这是「纯静态 + 零后端」方案无法回避的代价
- 所以定位结果的精度**只到省市**，再往下不做，页面上也不会显示更细的东西

## 为什么是一个单文件

没有构建、没有依赖、没有框架，一个 HTML 装下结构、样式和逻辑。理由有三个：改一句文案直接改文件就行；十年后它还打得开（只要浏览器还认 `<script>`）；以及，把 `scanlines`、`scan-beam`、`glitch` 这些放在一起看的时候，能一眼看出整个演出是怎么排的。这种「全部摊在桌面上」的透明感，本身也是这个玩具的一部分。

如果要做的话，下一步大概是：把省市的文案再拟得俏皮一点（现在是规规矩矩的「四川省广安市」），或者按距离给一句不同的收尾——不过那就是另一个玩具了。
