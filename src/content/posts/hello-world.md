你好呀，欢迎推开猫窝的门 🐾

这里是**藏枫的猫窝**——一个芙宁娜印象风、带点猫猫元素的个人博客。

## 这里会有什么

- **文章**：折腾记录、思考与日常
- **图库**：照片和截图的相册墙
- **星空猫座**：把所有文章变成星星的归档页
- **Now**：我最近在玩、在看、在听什么

## 网站是怎么搭的

本站基于 Astro 构建，部署在 GitHub Pages 上。设计上做了这些好玩的东西：

- 荒 / 芒双主题，右上角的**双色瞳**就是切换开关
- 按访客回访次数成长的**猫窝养成系统**——多来几次，猫窝会越来越热闹
- 每篇文章都可以**投喂猫粮**

代码块长这样：

```ts
const nest = { cat: '枫', theme: 'ousia' };
console.log(`欢迎来到${nest.cat}的猫窝`);
```

慢慢逛，别客气。猫不咬人，只撒娇。
